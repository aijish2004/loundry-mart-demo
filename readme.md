# Laundry Mart 🧺

A simple one-page website for a laundry and dry cleaning business.

## Features
* **Introduction:** Brief summary of laundry services.
* **Services List:** Bullet points of all services offered.
* **Pricing Table:** Simple table showing service costs in ₹ (Rupees).
* **Booking Form:** Input fields for user Name, Phone, and Email.

## How to Run
1. Make sure you have a picture named `loundry.png` in the same folder.
2. Open `index.html` in any web browser.
